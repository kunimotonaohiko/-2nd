# 富丘まごころ内科クリニック - 院内デジタルサイネージ

院内モニター用デジタルサイネージスライド（HTML）

## スライド構成

1. **新体制での診療と当院のご案内** - クリニック紹介・特徴タグ
2. **当院の内視鏡検査「4つの特徴」** - 4つの強みをカード表示
3. **院長紹介・ご挨拶** - 原田拓院長のプロフィール・略歴
4. **胃カメラ検査をおすすめする方** - 症状チェックリスト（14項目）
5. **大腸カメラ検査をおすすめする方** - 症状チェックリスト（9項目）
6. **ご案内・アクセス** - 電話番号・住所・地図

## 使用方法

`index.html` をブラウザで開くと、スライドが自動再生されます（1920×1080px対応）。

- 各スライド 12〜15秒で自動切替
- プログレスバーとナビゲーションドット付き
- フェードイン/アウトのトランジション効果
