GASTROSCOPY

胃カメラ検査をおすすめする方

このような症状はありませんか？ 早めの検査で重大な病気のリスクを最小限に抑えられます
✓ 胸やけ、吐き気、腹痛がある
✓ 酸っぱいものがこみあげる、胃酸が上がる
✓ 胃が痛い、胃もたれがある
✓ 空腹時のみぞおちの痛みや不快感
✓ お腹が張っている、食後にお腹が張る
✓ 喉の違和感・つかえ、げっぷが多い
✓ 食欲不振、急に食べられなくなった
✓ 便が黒っぽい
✓ ピロリ菌陽性、または検査歴がない
✓ 健診で要再検査の結果が出た
✓ 40歳以上で胃カメラ未経験
✓ 飲酒・喫煙が多い（過去も含む）
✓ 消化器がんの家族歴がある
✓ 胃が荒れていると言われた
一つでも該当する方は、お早めにご相談ください
COLONOSCOPY

大腸カメラ検査をおすすめする方

以下のいずれかに該当する場合は、症状の有無にかかわらずご相談ください
✓ 便潜血検査が陽性だった（1回でも）
✓ 血便・下血がある、排便時に出血する
✓ 便通異常（便秘・下痢）が3週間以上続く
✓ 腹痛や腹部膨満感が続く
✓ 原因不明の体重減少がある
✓ 健診で貧血（鉄欠乏性貧血）を指摘された
✓ 過去に大腸ポリープを指摘・切除した
✓ 40歳以上で大腸カメラ未経験
✓ 親族に大腸がん・ポリープの方がいる
このような症状が続く場合、大腸内視鏡検査をお受けください
