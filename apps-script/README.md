# Google スプレッドシート版 会議管理

専用アプリを作らず、Google スプレッドシート + Apps Script で「会議の入力・検索・類似会議の自動提案」を実現する構成です。

## できること

- 会議の名称・日時・参加者・目的を、社員(`@kenkohkai.jp` / `@kunimoto-hp.com`)が誰でも追加・編集できる
- スプレッドシートのフィルタや `Ctrl+F` で会議名・参加者・目的を検索
- 「会議名」または「目的」を入力すると、**趣旨が似ている既存会議があれば自動的に F 列にハイライト** され、「一緒に開催を検討: ○○ (XX%)」と表示される
- 編集履歴(誰がいつどのセルを変えたか)は Google が自動で保存(右クリック → 「編集履歴を表示」)

## 月額コスト・運用負担

- **0円**(既存の Google Workspace の中で完結)
- パッチ適用・サーバー管理は不要

## セットアップ手順(国本様の作業)

所要時間 約 10 分。

### 1. スプレッドシートを作成

1. https://sheets.google.com/ で新しいスプレッドシートを作成
2. ファイル名を「**会議一覧**」などに変更
3. **シート名(下のタブ)を「会議一覧」に変更** ← Apps Script がこの名前を参照します
4. 1 行目に以下のヘッダーを入力:

   | A | B | C | D | E | F |
   |---|---|---|---|---|---|
   | 会議名 | 開始日時 | 終了日時 | 参加者 | 目的 | 類似会議 (自動) |

5. 1 行目を選択 → メニュー「表示」→「固定」→「1 行」でヘッダーを固定
6. F 列のセル幅を広げる(類似会議の表示用)

### 2. 共有設定(両ドメインに編集権限を付与)

1. 右上の「**共有**」ボタンをクリック
2. 「全般的なアクセス」を「**制限付き**」のまま
3. 「ユーザーやグループを追加」に以下を入力して、それぞれ「**編集者**」権限で追加:
   - `kenkohkai.jp`(ドメイン全体に共有)
   - `kunimoto-hp.com`(ドメイン全体に共有)

   ※ 個別アカウントを 1 つずつ追加することもできますが、ドメイン共有が最も簡単です。
   ※ 「組織外への共有が制限されています」と出る場合は Workspace 管理者に「外部共有を許可するドメインに `kenkohkai.jp` と `kunimoto-hp.com` を追加」と依頼してください。

4. 「完了」をクリック

### 3. Apps Script を設置

1. メニュー「**拡張機能**」→「**Apps Script**」をクリック
2. プロジェクト名を「会議管理スクリプト」などに変更
3. デフォルトで `function myFunction() {}` だけ書かれているコード(`Code.gs`)を **全部削除**
4. 本リポジトリの [`apps-script/Code.gs`](./Code.gs) の中身を **すべてコピー** して、Apps Script エディタにペースト
5. 上部の **保存ボタン**(💾アイコン、または `Ctrl+S`)をクリック

### 4. 初回認可(1 回だけ)

Apps Script が編集を検知してセルに書き込めるよう、初回だけ実行権限の許可が必要です。

1. Apps Script エディタの上部、関数選択ドロップダウンで「**recalculateAll**」を選択
2. 「**実行**」ボタン (▶) をクリック
3. 「承認が必要です」と出るので「**権限を確認**」→ ご自身の Google アカウントを選択
4. 「Google で確認されていません」と警告が出たら、画面下の「**詳細**」→「**会議管理スクリプト(安全ではないページ)に移動**」をクリック
5. 「**許可**」をクリック
6. 「類似会議の再計算が完了しました。」というダイアログが出たら成功

### 5. 動作確認

1. スプレッドシートに戻る
2. メニューバーに「**会議管理**」というカスタムメニューが追加されていることを確認(初回はリロードが必要かも)
3. 試しに 2 行目以降に会議を 2 件入力してみる:

   | 会議名 | 開始日時 | 終了日時 | 参加者 | 目的 |
   |---|---|---|---|---|
   | 営業戦略 月次定例 | 2026/05/12 10:00 | 2026/05/12 11:00 | 田中, 佐藤 | 今四半期の営業目標達成に向けた戦略の確認 |
   | 営業部 戦略ミーティング | 2026/05/13 14:00 | 2026/05/13 15:00 | 田中, 山田 | 営業目標の進捗確認と次四半期の戦略立案 |

4. 2 件目の「目的」を入力した瞬間に F 列に「**一緒に開催を検討: 営業戦略 月次定例 (XX%)**」と表示されれば成功

## 運用上のヒント

### 検索したいとき

- **`Ctrl+F`**(Mac は `Cmd+F`) でシート全体から検索
- もしくは A1 セルの「**フィルタを作成**」アイコンで列ごとの絞り込み

### 編集者を確認したいとき

- セルを右クリック → 「**編集履歴を表示**」
- 全体の変更履歴は ファイル → 「**変更履歴**」→ 「**変更履歴を表示**」

### 類似度の閾値や表示件数を変えたいとき

`Code.gs` の上部にある以下の値を変更してください:

```javascript
const SIMILARITY_THRESHOLD = 0.2;  // 0.0〜1.0。下げるとより多くの会議が「類似」と判定される
const TOP_N = 3;                    // 表示する類似会議の最大件数
```

変更後、Apps Script エディタで保存(`Ctrl+S`)するだけで反映されます。

### スマートフォンから使うとき

Google Sheets のモバイルアプリで普通に編集できます。Apps Script のトリガーも同様に発火します。

## トラブルシューティング

### F 列に類似会議が表示されない

- シート名が **「会議一覧」になっているか** 確認(タブの名前)
- Apps Script が **保存済みか** 確認
- 初回認可が完了しているか(上記「4. 初回認可」)
- メニュー「会議管理」→「類似会議を全行で再計算」を実行してみる

### 「組織外への共有が制限されています」と出る

Workspace 管理者に以下を依頼してください:

> Google 管理コンソール → ドライブとドキュメント → 共有設定で、`kenkohkai.jp` と `kunimoto-hp.com` を相互に「信頼できる組織」として追加

### スクリプトを変更したのに動作が変わらない

- Apps Script エディタで **保存** したことを確認
- スプレッドシートを再読み込み(`Ctrl+R`)
